python demo.py

STEP 03

接入自己的 Agent

使用可观测重试包装器，或在已有重试逻辑里调用 tracer.emit()。不要给有副作用且不幂等的调用随意增加重试。

from agent_observer import (
  AgentTracer, observed_retry_async
)

tracer = AgentTracer("my-agent").start()
try:
  result = await observed_retry_async(
    call_tool, tracer, "search-tool",
    max_attempts=3,
    retryable=(TimeoutError,)
  )
except Exception:
  tracer.finish("failed")
  raise
else:
  tracer.finish("succeeded")
观测插件只能记录接入了事件钩子的执行，不能自动读取 Codex、Claude 或第三方服务内部不可见的重试。
